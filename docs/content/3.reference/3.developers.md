Python 3.11 or newer. Install the test tools with:

```bash
python3 -m pip install -e ".[dev]"
pytest
ruff check src tests
```

Tests use HTML fixtures and `httpx.MockTransport`. Do not add a test that contacts avherald.com.

## Layout

| Path | Role |
| --- | --- |
| `src/avherald_scraper/cli.py` | Arguments and exit codes |
| `src/avherald_scraper/config.py` | CLI, then `config.ini`, then defaults |
| `src/avherald_scraper/urls.py` | Ids, canonical URLs, list `opt` bits |
| `src/avherald_scraper/parser.py` | Listing HTML to records, and the next URL |
| `src/avherald_scraper/http.py` | Delay, block detection, proxy rotation |
| `src/avherald_scraper/db.py` | SQLite schema, upsert, bookmark |
| `src/avherald_scraper/export.py` | JSON, CSV, and XLSX copies |
| `src/avherald_scraper/scraper.py` | Page loop and progress bar |
| `docs/` | This site |

`main.py` is only an editor shortcut. The supported command is `avherald-scraper`.

## Dependencies

Runtime packages are `beautifulsoup4`, `lxml`, `httpx`, and `anyio`. Declare them in `pyproject.toml`. Do not add `requirements.txt` or `python-dotenv`.

## A change that users can see

Add a Conventional Commit and a line under `## [2.0.0] - Unreleased` in `CHANGELOG.md`. The docs site copies that file at build time.
