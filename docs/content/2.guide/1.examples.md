These examples assume you already installed the command and you are in the project folder.

## Print three incidents

```bash
avherald-scraper --limit 3 --category incident --format cli
```

## Take the next 50, quietly

```bash
avherald-scraper --limit 50 --quiet
```

The file grows. The terminal stays empty when nothing goes wrong.

## Incidents and accidents, oldest occurrence first

```bash
avherald-scraper --category incident --category accident --sort occurrence --limit 20
```

You can also write `--category incident,accident`.

## Preview without saving

```bash
avherald-scraper --dry-run --limit 5 --verbose
```

You see the rows. The database file is not created or changed.

## See the settings before you run

```bash
avherald-scraper --show-config --limit 3 --format cli
```

Flags you pass here win over `config.ini`.

## Slow down, or use a proxy

```bash
avherald-scraper --delay 5 --limit 10
avherald-scraper --proxy http://127.0.0.1:8080 --proxy http://127.0.0.1:8081
```

If one proxy is banned, the same page is tried on the next proxy. When every proxy fails, the command stops.

## What a blocked run looks like

The process exits with status `1` and prints the reason. Set `proxy` in `config.ini`, or pass `--proxy`, and run the command again.

A bad category or a missing config file exits with status `2`. A finished run exits with status `0`.
