Start with a tiny run so you can see the shape of the result.

## Save three headlines

```bash
avherald-scraper --limit 3 --format cli
```

`--format cli` prints the rows in the terminal, with space between the category, the date, the headline, and the link. Use it when you only want a handful of items.

The same three rows are also stored in `data/avherald.sqlite`, so a later run knows they already exist.

## Read the summary

When the crawl finishes, the terminal prints a short tally:

```text
3 kept   3 new
data/avherald.sqlite   3 stored
```

A progress bar stays on the screen while pages are downloading. `--quiet` hides the bar and the tally.

## Look at the database

```bash
sqlite3 data/avherald.sqlite "SELECT category, list_date_iso, heading FROM articles;"
```

## Run it again

```bash
avherald-scraper --limit 3 --format cli
```

Already stored ids do not count toward the limit. The command continues from the saved list page and looks for three headlines it has not stored yet.

`--fresh` forgets that saved position and starts at the first list page. Stored rows stay unique.
