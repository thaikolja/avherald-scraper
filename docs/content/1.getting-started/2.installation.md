You need Python 3.11 or newer. The package name on your computer is `avherald-scraper`. The project name is The Aviation Herald Scraper.

## Install from a checkout

```bash
python3 -m pip install .
avherald-scraper --version
```

## Keep it in a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install .
```

On Windows the activate script is `.venv\Scripts\activate`.

## Install with pipx

From the repository root:

```bash
pipx install .
```

`pipx` puts the command in its own environment, which is what you want if you only run the tool and do not change it.

## Check that it works

```bash
avherald-scraper --help
avherald-scraper --show-config
```

`--show-config` prints the settings it would use and exits. It does not download anything and it does not create a database.
