Open an issue or a merge request against the `v2` branch on [GitLab](https://gitlab.com/thaikolja/avherald-scraper). GitHub receives a push mirror. Edit on GitLab. An edit on GitHub is overwritten by the next mirror.

Read [CONTRIBUTING.md](https://gitlab.com/thaikolja/avherald-scraper/-/blob/main/CONTRIBUTING.md) in the repository for the setup commands.

Do not add article-body downloads, parallel fetches, or a way to redistribute the headlines. Tests must not call avherald.com.
